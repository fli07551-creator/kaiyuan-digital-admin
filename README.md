### 1.2 抓取方式（本次相比上一版的改进）
上一版只能依据用户提供的 3 张截图还原；本版**成功登录系统**，直接抓取了真实页面结构与菜单：

1. **登录链路逆向**：登录页表单用 RSA 公钥（JSEncrypt）加密密码，接口为
   `POST library/libData.html?type=adLogin`，参数 `userName / prove(图形验证码) / coid / sign(加密密码)`。
2. **验证码识别**：图形验证码按会话绑定且一次性，通过 curl 保持会话 + 多次裁剪放大人工识别完成登录。
3. **真实结构提取**：登录后主页通过 iframe 加载（`cla=homepage&fun=home&menuType=个人中心`），
   主页卡片为「快捷入口(0) / 待办事项(0) / 消息中心(0) / 我的任务(0) / 公司通知(0)」。
4. **真实菜单树**：从主框架 HTML 的 `menuOne`（一级）/ `menuTwo`（二级）属性解析出完整菜单：
   **15 个一级模块、89 个二级菜单**（见 `src/lib/menu.ts`）。

## 五、运行

```bash
npm install        # 或复用上级目录 node_modules
npm run build
npm start          # http://localhost:3001
```

> 环境提示：本机 node 安全 shim 会拦截 `.next/trace` 新建写操作与批量删除。
> 构建前先建空占位文件：`python -c "import os;os.makedirs('.next',exist_ok=True);open('.next/trace','w').close()"`，
> 再执行 `NEXT_TELEMETRY_DISABLED=1 npm run build`。不要用 `npm run dev`（清缓存会被拦截）。

## 六、GitHub 同类开源项目调研（Craft Anything 对标）

围绕「Craft Anything（研究→构建→校验→迭代的网站/应用复刻工具）」调研到 3 个直接对标项目：

### 6.1 项目对比

| 项目 | Star / 许可 | 核心思路 | 与本任务的关联 |
| --- | --- | --- | --- |
| **storytold/craft-anything** | ~1.4万（上线一周）/ MIT + Apache-2.0 | 先研究（截图/链接/文件）再交给编码 Agent 构建，300+ 工具，净室模式（仅外观）与深度模式（读源码）双模式，MCP 协议，Rust 实现 | **直接对标**。本任务的流程（登录抓取→提取结构→重建→校验）就是它的 Study→Build→Check 思路的手工版 |
| **JCodesMore/ai-website-cloner-template** | ~5900 / MIT | 一条命令把任意网站重建为可维护的 Next.js 源码；五阶段流水线（侦察→基础→组件规格→并行构建→QA）；输出 Next.js 16 + TypeScript + shadcn/ui | **最贴近本项目技术栈**。其 `docs/research/` 产物理念（组件规格、设计令牌提取）可借鉴到复刻文档 |
| **abi/screenshot-to-code** | ~8万 / MIT | 截图/录屏/Figma → HTML/React/Vue 等代码，需自带模型 Key | 截图转代码的经典方案；本任务早期只有截图时的思路来源 |

### 6.2 可借鉴点（已融入本次复刻）

1. **Study 先行**：不急着写代码，先逆向目标站点的登录、菜单、iframe 结构——对应 craft-anything 的「深度研究拆解」。
2. **设计令牌提取**：抓取原站主色后替换为浅绿主题（`#2e9e63`），保留结构、替换外观——对应 cloner-template 的 design token 提取。
3. **可维护源码而非 HTML 快照**：输出结构化 Next.js 组件（AppShell / menu / dashboard 数据层），不是一次性抓取页面。
4. **QA 校验**：构建后逐项核对菜单数量（15/89）、主页卡片文案、HTTP 200 与浏览器截图。

### 6.3 结论

Craft Anything 类是「通用自动复刻引擎」，本任务是「单站深度复刻 + 品牌/主题改造 + 自有数据模块融入」。
方法论一致（研究→构建→校验），但本项目多了两步：**真实业务数据聚合**与**品牌重塑**，这是通用工具无法代劳的业务工作。
